# VaiDarBanhoOCao 

Prova de Aptidão Profissional (PAP) - Curso Profissional de Técnico/a de Gestión e Programação de Sistemas Informáticos / Informática.

##  Sobre o Projeto
O **VaiDarBanhoOCao** é uma aplicação de desktop desenvolvida em **C# (.NET)** com o objetivo de gerir um estabelecimento de banhos e tosquias para animais. O sistema permite otimizar o dia a dia do espaço, facilitando o registo e controlo de clientes, animais, marcações de serviços e consultas.

## 🚀Funcionalidades Principais
* **Gestão de Clientes:** Registar, consultar e editar dados dos donos dos animais.
* **Gestão de Animais:** Associar pets aos respetivos donos e registar características (raça, porte, etc.).
* **Marcação de Serviços:** Agendar banhos, tosquias e outros serviços disponíveis.
* **Consulta de Registos:** Visualizar histórico e dados guardados na base de dados.

##  Tecnologias Utilizadas
* **Linguagem:** C# (Windows Forms)
* **Base de Dados:** MySQL (`pap_cao.sql`)
* **Interface / Design:** MaterialSkin
* **Ambiente de Desenvolvimento:** Visual Studio

##  Como Executar o Projeto
1. Clona ou descarrega este repositório.
2. Abre o ficheiro `.sln` no **Visual Studio**.
3. Importa o ficheiro de base de dados (`pap_cao.sql`) para o teu servidor MySQL local (por exemplo, via phpMyAdmin ou Workbench).
4. Configura a string de ligação à base de dados no projeto, se necessário.
5. Compila e executa a aplicação (`F5`).
